# Install skills

Agent skills (`SKILL.md`) that set up an almighty server. Give one to a
coding agent on the machine that will run the server, or read it as a
checklist. Each one ends with checks to run before calling it done.

- `install-personal`: one person, one machine, loopback only.
- `install-server`: a VPS or home server reached over HTTPS.
- `install-company`: inside a company network, sign-in through the
  company's identity provider.
